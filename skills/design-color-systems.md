## Core Principle

Good color design is not based only on whether individual colors look beautiful.

Good color design comes from the relationship between colors.

Colors work well together when their hue distance, saturation, brightness, and usage proportion create harmony, contrast, hierarchy, and readability.

Think of color like music: individual notes matter, but the harmony comes from the relationship between them.

---

## Common Color Mistakes to Avoid

### 1. Choosing colors only by intuition

Do not choose colors just because they “feel right.”

Always evaluate:

* Hue relationship
* Brightness
* Saturation
* Contrast
* Area proportion
* UI function

### 2. Copying color codes without understanding them

Do not simply copy another design’s palette.

A palette may work in one context but fail in another if the layout, background, content density, or brand mood changes.

### 3. Using too many saturated colors

Avoid using many high-saturation colors at the same time.

Too many intense colors create visual noise and make the interface feel chaotic.

## Color Wheel Basics

The color wheel is the foundation of color harmony.

A basic 12-color wheel includes:

* Red
* Red-orange
* Orange
* Yellow-orange
* Yellow
* Yellow-green
* Green
* Blue-green
* Blue
* Blue-purple
* Purple
* Red-purple

Color relationships are based on distance on the color wheel.

### Key relationships

#### Adjacent colors create harmony

Colors next to each other on the color wheel feel natural and unified.

Example:

* Red
* Orange
* Yellow

#### Opposite colors create contrast

Colors opposite each other create strong visual tension and high impact.

Example:

* Red and green
* Blue and orange
* Yellow and purple

#### Equally spaced colors create balance

Colors placed at equal distances around the wheel create rich but balanced palettes.

Example:

* Red
* Yellow
* Blue

# Six Practical Color Rules

## 1. Complementary Colors

### Definition

Complementary colors are two colors directly opposite each other on the color wheel.

Examples:

* Red and green
* Blue and orange
* Yellow and purple

### Effect

Complementary colors create the strongest visual contrast.

They are useful when an element needs to stand out immediately.

### Best use cases

Use complementary colors for:

* CTA buttons
* Promotions
* Sports branding
* Food packaging
* Highlight elements
* Interfaces that need energy and impact

### How to use

Do not split complementary colors evenly.

Use one color as the dominant color and the other as a small accent.

Recommended proportions:

* 80% dominant color / 20% accent color
* 70% dominant color / 30% accent color

### Avoid

Avoid using both colors at equal visual weight.

A 50/50 split makes the colors compete and can feel loud or uncomfortable.

---

## 2. Analogous Colors

### Definition

Analogous colors are 2–3 colors next to each other on the color wheel.

Examples:

* Red, orange, yellow
* Blue, blue-green, green
* Purple, red-purple, red

### Effect

Analogous colors feel harmonious, safe, soft, and unified.

They are useful for building a consistent visual atmosphere.

### Best use cases

Use analogous colors for:

* Brand identity
* Personal websites
* Social media backgrounds
* Nature-inspired design
* Calm and unified interfaces
* Gradient-based visuals

### How to use

Choose one dominant color.

Use the other nearby colors as supporting colors.

When using three analogous colors, the middle color often works well as the main color, while the two side colors act as support.

Add neutral colors such as black, white, or gray to create visual breathing room.

### Avoid

Analogous palettes can lack focus because the colors are similar.

Add contrast through:

* Neutral colors
* Brightness differences
* Saturation differences
* One small accent color

---

## 3. Triadic Colors

### Definition

Triadic colors are three colors equally spaced around the color wheel, forming a triangle.

Example:

* Red
* Yellow
* Blue

### Effect

Triadic palettes are colorful, balanced, and energetic.

They are a safer way to use multiple colors without making the design feel random.

### Best use cases

Use triadic colors for:

* Children’s products
* Game interfaces
* Event visuals
* Playful brands
* Creative campaigns
* Designs that need energy and variety

### How to use

Use a clear proportion system.

Recommended proportion:

* 70% main color
* 25% supporting color
* 5% accent color

### Avoid

Do not use all three colors at equal strength.

Do not use all three colors at full saturation.

Reduce the saturation or brightness of one or two colors, and keep only one color as the main visual focus.

---

## 4. Split-Complementary Colors

### Definition

Split-complementary color schemes use:

* One main color
* The two colors next to its direct complementary color

Example:

If the main color is red, its complement is green.

Instead of using green directly, use the colors beside green, such as blue-green and yellow-green.

### Effect

Split-complementary schemes preserve contrast but feel softer and easier to control than direct complementary palettes.

They are more dynamic than analogous palettes but less aggressive than complementary palettes.

### Best use cases

Use split-complementary colors for:

* Movie posters
* Game UI
* Brand visual systems
* Distinctive but controlled designs
* Designs that need personality without being overwhelming

### How to use

Use the main color as the large-area base.

Use the two split-complementary colors for smaller decorations, highlights, secondary actions, or visual accents.

### Why it is useful for beginners

Split-complementary color design is a good practice method because it is more interesting than analogous color design, but easier to control than direct complementary color design.

---

## 5. Tetradic / Rectangular Color Schemes

### Definition

Tetradic color schemes use four colors arranged as a rectangle on the color wheel.

They usually contain two complementary color pairs.

Example:

* Red
* Green
* Blue
* Orange

### Effect

Tetradic palettes are rich, colorful, and powerful.

They are also difficult to control because they contain multiple strong contrasts.

### Best use cases

Use tetradic colors for:

* Game interfaces
* Children’s brands
* Large event visuals
* Infographics
* Complex systems that require color-coded categories

### How to use

Choose one absolute dominant color.

Use the other three colors with controlled proportions.

Example:

* 50% dominant color
* 30% secondary color
* 15% support color
* 5% accent color

Reduce the brightness or saturation of at least two colors.

### Avoid

Do not use four highly saturated colors equally.

This creates visual overload.

Beginners should practice complementary, analogous, triadic, and split-complementary schemes before using tetradic palettes.

---

## 6. The 60-30-10 Rule

### Definition

The 60-30-10 rule is not a color scheme.

It is a proportion rule for assigning color areas.

It can be used with any color relationship.

### Standard ratio

* 60% main color
* 30% secondary color
* 10% accent color

### UI usage

#### 60% Main color

Use for:

* Background
* Base surface
* Primary layout area

This color sets the overall mood.

It does not need to be visually loud.

Examples:

* White
* Light gray
* Dark gray
* Deep navy
* Soft beige

#### 30% Secondary color

Use for:

* Cards
* Sidebars
* Content blocks
* Sections
* Secondary surfaces

This color should be different from the main color but not visually conflicting.

It is often a lighter, darker, warmer, or cooler variation of the main color.

#### 10% Accent color

Use for:

* CTA buttons
* Links
* Highlights
* Active states
* Important labels
* Notifications

This color should guide attention.

It can be more saturated because the area is small.

### Key rule

If the proportion is right, even an ordinary palette can look acceptable.

If the proportion is wrong, even a sophisticated palette can fail.

# Practical UI Color Workflow

## Step 1: Define the design goal

Before choosing colors, define the emotional and functional goal.

Ask:

* Should the UI feel calm or energetic?
* Should it feel professional or playful?
* Should the user focus on reading or taking action?
* Is the brand serious, friendly, luxurious, technical, natural, or creative?

---

## Step 2: Choose the main color first

Do not start by choosing many colors.

Start with one main color based on:

* Brand identity
* Product personality
* User emotion
* Industry expectations
* Visual hierarchy

Then derive supporting and accent colors using color wheel relationships.

---

## Step 3: Choose a color harmony method

Select one of the following based on the design goal:

| Goal                       | Recommended color rule   |
| -------------------------- | ------------------------ |
| Strong contrast            | Complementary            |
| Safe and harmonious        | Analogous                |
| Colorful but balanced      | Triadic                  |
| Interesting but controlled | Split-complementary      |
| Rich multi-color system    | Tetradic                 |
| Any UI system              | 60-30-10 proportion rule |

---

## Step 4: Adjust saturation and brightness

After choosing hues, refine the palette using HSL:

* Hue determines color family
* Saturation determines intensity
* Lightness determines brightness

Often, adjusting saturation and brightness is more effective than changing hue.

For example:

* A saturated blue feels energetic and digital
* A desaturated blue feels calm and professional
* A light blue feels soft and friendly
* A dark blue feels stable and trustworthy

---

## Step 5: Add neutral colors

Most UI systems need neutral colors.

Use neutrals for:

* Backgrounds
* Text
* Borders
* Dividers
* Disabled states
* Cards
* Layout structure

Neutral colors create breathing room and prevent colorful elements from overwhelming the interface.

Useful neutrals include:

* White
* Black
* Warm gray
* Cool gray
* Off-white
* Near-black

---

## Step 6: Limit the palette

For most UI systems, keep the core palette within 3–5 colors.

Recommended structure:

* 1 main color
* 1–2 supporting colors
* 1 accent color
* Neutral colors for text, backgrounds, borders, and surfaces

Too many colors weaken brand recognition and make the design system harder to maintain.

---

## Step 7: Test contrast and accessibility

Beautiful colors are not enough.

The UI must remain readable.

Always check contrast between:

* Text and background
* Buttons and button labels
* Links and surrounding text
* Disabled states and active states
* Error messages and background
* Cards and page background

For normal body text, aim for at least WCAG 4.5:1 contrast.

If text is hard to read, the color design has failed regardless of aesthetics.

---

## Step 8: Validate in real context

Do not judge colors only inside a design tool.

Test colors in real usage conditions:

* Mobile screen
* Desktop screen
* Light mode
* Dark mode
* Low brightness
* Bright daylight
* Different monitors
* Real content density
* Different UI states

Colors that look good in Figma may look different on actual devices.

# Decision Guide for LLMs

When asked to design a UI color palette, follow this decision logic:

## If the user wants a calm and unified UI

Use an analogous palette.

Reduce saturation.

Add neutral backgrounds.

Use accent color sparingly.

## If the user wants a high-impact CTA

Use complementary colors.

Keep the complementary color as a small accent.

Avoid equal area distribution.

## If the user wants a playful or energetic brand

Use triadic colors.

Reduce saturation on at least one color.

Use 70-25-5 or 60-30-10 proportions.

## If the user wants something distinctive but not too loud

Use split-complementary colors.

Use the main color broadly.

Use the split colors for highlights and decorative elements.

## If the user needs multiple category colors

Use tetradic or extended palettes carefully.

Assign each color a function.

Avoid using all colors decoratively.

Use neutral UI surfaces to stabilize the palette.

## If the UI feels messy

Check these issues first:

* Too many saturated colors
* No dominant color
* Accent color used too much
* Poor contrast
* No neutral space
* Colors have equal visual weight
* Brightness and saturation are not controlled

# Prompt Pattern for LLMs

When creating a UI color palette, use this reasoning pattern:

```markdown
1. Identify the product mood and design goal.
2. Choose one main color.
3. Select a color harmony rule based on the goal.
4. Assign colors using 60-30-10 proportions.
5. Adjust saturation and brightness to control intensity.
6. Add neutral colors for readability and structure.
7. Check contrast and accessibility.
8. Explain where each color should be used in the UI.
```

# Final Checklist

Before finalizing a UI color palette, verify:

* There is one clear dominant color
* Accent colors are used sparingly
* The palette has enough neutral space
* Saturation is controlled
* Brightness differences create hierarchy
* Text contrast is readable
* CTA elements stand out clearly
* Colors are tested in real UI context
* The palette supports the product mood
* The system can scale across pages and components
