# Serenity Wellness App Design

Use this skill to create, refine, or extend landing page content and UI layouts for the **Serenity** wellness app brand.

## Brand Concept

Serenity is a calm, modern wellness app focused on meditation, sleep, fitness tracking, mood tracking, and complete wellbeing.

Primary message:

> Find Your Inner Peace

Supporting message:

> Meditation, fitness tracking, and sleep analysis all in one beautiful app. Start your wellness journey today.

## Visual Style

Create a soft, spacious, peaceful, premium app landing page.

Style traits:

- Clean wellness-focused SaaS/app landing page
- Soft rounded cards
- Gentle gradients
- Large serif headline paired with simple sans-serif body text
- Light background with floating mobile UI mockups
- Calm, trustworthy, optimistic tone
- Minimal clutter
- Green call-to-action buttons
- Pastel wellness colors

## Color Palette

Use these colors consistently:

- Sky blue: `#87CEEB`
- Light green: `#90EE90`
- Primary green: `#22C55E`
- Background light gray: `#F5F5F5`

Recommended usage:

- Use `#22C55E` for primary buttons, highlights, check icons, and positive status elements.
- Use `#90EE90` for wellness gradients, soft accents, and secondary highlight text.
- Use `#87CEEB` for calm progress rings, sleep-related visuals, and subtle gradient accents.
- Use `#F5F5F5` for the page background.

## Writing Rules

- Use calm, reassuring, wellness-focused language.
- Keep copy short and emotionally warm.
- Emphasize peace, balance, sleep, clarity, progress, and healthy routines.
- Avoid aggressive sales language.
- Avoid clinical or medical claims.
- Keep CTAs simple and action-oriented.
- Maintain a premium but friendly app-store landing page feel.

## Layout Rules

- Use generous spacing.
- Use large rounded corners.
- Use soft shadows.
- Use green primary buttons.
- Use subtle blue-green gradients for wellness highlights.
- Keep cards visually light and airy.
- Make the hero feel calm and aspirational.
- Pair product benefits with simple UI proof points such as streaks, scores, and progress.

## Output Expectations

When asked to create a design, provide complete section-based landing page content or implementation-ready UI copy.

When asked to generate code, preserve this brand structure and color palette.

When asked to rewrite content, keep the Serenity wellness tone and avoid changing the core product positioning.
